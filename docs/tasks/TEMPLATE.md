# 作業記録テンプレート

正本：[workflow-rules.md](../workflow-rules.md)。反復手順：[loop-workflow.md](../loop-workflow.md)。窓口Codexが必要項目を記録する。秘密情報と非公開の内部証拠は承認済みのGit管理外へ置く。以下の空欄は承認・合格・実施済みを意味しない。

## 記入量

全作業で必要なのは、識別・目的と範囲／固定した合格条件／承認の出所／実物と保全／レビュー区分と必要な検証／累積実行枠／現在の状態と次の操作／判断と証拠参照の8組。以下の欄へ書き、同じ内容を重複記載しない。

自動実行・外部変更・公開・結果不明等の欄は該当時に埋め、未使用は理由付き「対象外」を1行で示せる。未確認を対象外へ置き換えず、必須レビュー・承認・合格条件・失敗履歴を省略しない。
